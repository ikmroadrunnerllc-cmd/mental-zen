# C4: Low-Latency AI Degradation & Deterministic Fallback

**Labels:** `challenge`, `owner-mine`

## Description
Fault-tolerant AI emotional reflection delivery with zero-latency baseline execution.

## Acceptance Criteria
- [ ] Server-side Gemini 2.5 Flash callable generates actionable reflection (<160 chars) within 4 seconds.
- [ ] Network latency > 4.0 seconds, HTTP 500 error, or offline state triggers immediate fallback to local pure Dart lexicon engine.
- [ ] Complete API disconnection gracefully surfaces local lexicon sentiment score with visible "Low Confidence" badge without throwing unhandled exceptions.
