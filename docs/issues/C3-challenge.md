# C3: Accessibility & Touch Ergonomics

**Labels:** `challenge`, `owner-mine`

## Description
Strict Material 3 accessibility compliance, touch target sizing, and high-contrast readability.

## Acceptance Criteria
- [ ] All interactive elements (mood buttons, back navigation, save triggers) maintain at least 48x48dp interactive bounding boxes.
- [ ] System high-contrast mode and dynamic color theming preserve legible contrast ratios (>= 4.5:1 for body copy, >= 3:1 for controls).
- [ ] Screen reader (TalkBack) traversal provides semantic labels for icon-only buttons, streak counts, and mood rating pills.
