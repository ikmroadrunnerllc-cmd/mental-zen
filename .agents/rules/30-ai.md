- Contract in `docs/ai-contract.md` is frozen. Changing inputs, outputs, or the
  metric needs my explicit approval first.
- The lexicon scorer is the baseline. It runs first, always, and is persisted
  even when the model succeeds.
- Every model call has: timeout, one retry, fallback to baseline on failure,
  Crashlytics non-fatal with the error code.
- Prompts strip PII: regex out capitalised first names before sending.
- Prompt text lives in `functions/src/prompts/` with a version constant. Bump
  the version on any change and note it in the eval log.
- After an eval run, record: accuracy, kappa, p95 latency, fallback rate, and
  every case where the model beat or lost to the baseline. Losses get a written
  cause, not a fix.
