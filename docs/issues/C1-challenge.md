# C1: Responsive Layout & Viewport Scaling

**Labels:** `challenge`, `owner-mine`

## Description
Dynamic screen scaling across multiple Android device profiles, densities, and orientations (phones 360dp–412dp width and small tablets).

## Acceptance Criteria
- [ ] UI conforms to 390x844 SVG specifications without text truncation or overflow bars on standard viewports.
- [ ] Narrow 320dp width devices and extreme system font scaling (up to 200%) dynamically wrap buttons and preserve legible entry cards.
- [ ] Overflow errors (`A RenderFlex overflowed...`) are prevented via scrollable shells and responsive constraints.
